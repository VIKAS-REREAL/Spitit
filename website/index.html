Features

Everything you need,
nothing you don't.

Sub-second
transcription

Groq's LPU inference means ~350ms from hotkey release to text on screen. No cloud roundtrip delay. No waiting animation.

Paste into
any app

Whatever window has focus gets the text. Cursor, Notion, Gmail, Slack, VS Code, WhatsApp Web — it just works.

100% private,
zero middlemen

Audio goes from your mic to Groq over encrypted TLS. No Spitit servers. No logging. No data retention. Period.

Hinglish
actually works

"Meeting 6 baje start karte hain bhai" — comes out exactly like that, in Roman script, correctly. Not transliterated garbage.

Custom
hotkey

Hold Alt + LShift to record. Change it to anything. Toggle mode, hold mode — your workflow, your rules.

System tray,
zero distraction

No window in your face. The only UI is the floating pill during recording — which vanishes the instant transcription finishes.

Getting started

Three steps,
then it's yours.

Step 01

Get a free
Groq API key

Visit console.groq.com. Sign up free. Copy your API key. The free tier handles heavy daily use easily.

Step 02

Download
and install

Run the installer. When prompted, paste your Groq API key. No terminal required. No Python. Launches in system tray and stays there.

Step 03

Hold, speak,
release.

Press Alt + LShift and speak. Release when done. ~350ms later your words appear, clean, wherever your cursor was.
