# Getting Support for Spitit

Thank you for using Spitit! Here is how to find help, report issues, and interact with the community.

---

## 1. Documentation & Troubleshooting

Before opening an issue, please check:
- [Architecture & FAQ](./docs/ARCHITECTURE.md)
- [Project Roadmap](./docs/ROADMAP.md)
- [Privacy Policy](./PRIVACY.md)

Common troubleshooting steps:
- **Hotkeys not firing in Games or Elevated Windows**: Windows UIPI (User Interface Privilege Isolation) prevents standard apps from receiving hotkeys while an elevated window is focused. Run Spitit as Administrator if dictation is needed in elevated environments.
- **Microphone Blocked**: Verify that Windows Settings -> Privacy & Security -> Microphone has "Let desktop apps access your microphone" enabled.
- **API Key Errors**: Test your Groq API key in Spitit Settings -> Groq API Key -> "Test Connection".

---

## 2. Community Discussions & Q&A

For general questions, configuration tips, and feature ideas:
- Visit [GitHub Discussions](https://github.com/VIKAS-REREAL/Spitit/discussions).

---

## 3. Reporting Bugs

If you find a reproducible bug:
- Open a bug report using the [GitHub Issue Tracker](https://github.com/VIKAS-REREAL/Spitit/issues).
- Please include your Windows version (10 or 11), configured hotkey, microphone model, and reproduction steps.

---

## 4. Security Disclosures

For security vulnerabilities, please refer to our [Security Policy](./SECURITY.md) and report privately via GitHub Private Vulnerability Reporting.
