User Guide

Master Spitit
in minutes.

Four steps from install to speaking your first message.

01

Get your Groq API key

Visit console.groq.com, create a free account, and copy your API key. Takes about 90 seconds.

02

Install Spitit

Download the Setup installer, run it, and paste your API key when prompted. That's the entire setup.

03

Hold hotkey, speak

Hold Alt + LShift and speak naturally. The pill appears in the corner while you record.

04

Release and it's pasted

Release the hotkey. In ~350ms, clean text appears wherever your cursor was — no extra steps needed.

Step 01 — Setup

Get your free Groq API key

Spitit uses Groq's lightning-fast LPU to transcribe your voice. You need a free Groq API key to connect.

1. Go to console.groq.com
2. Create a free account (no card required)
3. Click API Keys → Create API Key
4. Copy the key — you'll paste it during install

# The free tier is plenty for heavy daily use
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxx

Tips & FAQ

Common questions

Does it work offline?

No — Spitit sends audio to Groq's API over the internet. You need an active connection. Audio never touches our servers, only Groq's.

Can I change the hotkey?

Yes. Right-click the system tray icon → Settings → Hotkey. You can set any key combination or switch to toggle mode (press once to start, press again to stop).

Does it support Hinglish?

Yes, naturally. Speak a mix of Hindi and English and Spitit outputs clean Roman script. Whisper Large-v3 Turbo handles code-switching well.

How do I build from source?

Clone the repo, install requirements, and run main.py. See the README for full instructions.

Is it really free?

Spitit itself is free and MIT licensed. You pay nothing. The only potential cost is Groq API usage if you exceed the free tier — which is generous enough for heavy use.
